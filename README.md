# Versa
Universal Fortnite backend base written in TypeScript



>[!NOTE] 
> Since this backend only meant for testing things for my self and to obv use as base in the future so dont exept this backend to have many features!

<summary>Tested FN versions</summary>

|-|-|-|
| 1.7.2 | not yet | Windows |
| 1.8.2 | not yet | Windows |


</details>

<details>

<summary>Run & setup</summary>

- 1.) Rename: *`example.env`* to **`.env`**
- 2.) Get **Bun** from here: https://bun.sh/
- 3.) Go to **`Versa\`** folder then Run: *`bun install`*
- 4.) Run the backend with *`bun run src/index.ts`*



</details>
